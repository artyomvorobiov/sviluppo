# Каталог выпусков: формат и правила

Все рекомендации «Квартета» лежат в одном файле — [`Shared/Resources/catalog.json`](../Shared/Resources/catalog.json).
Он встроен в приложение и виджет, а при желании может обновляться из интернета (см. «Удалённый каталог» ниже).
Тот же файл без изменений подойдёт для будущей версии под Android.

## Как выпуски попадают в дни

- Выпуск № 1 показывается в день первого запуска, № 2 — на следующий день и так далее.
- Когда выпуски заканчиваются, они идут по кругу с первого.
- В архиве — все дни от первого запуска до сегодняшнего.

Поэтому **новые выпуски добавляйте в конец списка**: вставка в середину сдвинет уже прошедшие дни в архиве.

## Структура файла

```json
{
  "schemaVersion": 1,
  "updated": "2026-10-20",
  "issues": [
    {
      "id": "winter",
      "theme": "Зима",
      "intro": "Короткое вступление: чем связаны четыре рекомендации.",
      "items": [ { "...": "картина" }, { "...": "статья" }, { "...": "альбом" }, { "...": "фильм" } ]
    }
  ]
}
```

| Поле выпуска | Обязательно | Описание |
|---|---|---|
| `id` | да | Уникальный идентификатор латиницей: `winter`, `night-city`. |
| `theme` | да | Тема дня — крупный заголовок на главном экране. |
| `intro` | да | Вступление на 2–4 предложения. |
| `items` | да | Рекомендации: по одной каждого типа (`painting`, `article`, `album`, `film`). |

## Поля рекомендации

| Поле | Обязательно | Описание |
|---|---|---|
| `id` | да | Уникальный идентификатор: `painting-hunters-in-the-snow`. По нему же строятся ссылки `kvartet://item/<id>`. |
| `kind` | да | `painting`, `article`, `album` или `film`. |
| `title` | да | Название по-русски. Для альбомов обычно оригинальное. |
| `originalTitle` | | Оригинальное название — показывается под заголовком и используется для поиска обложек. |
| `creator` | да | Художник, автор, исполнитель или режиссёр. Для статей — издание («Википедия», «Arzamas»). |
| `originalCreator` | | Имя латиницей, если `creator` по-русски (нужно для поиска в iTunes). |
| `year` | | Год или период: `"1565"`, `"1884–1886"`, `"ок. 1508"`. |
| `minutes` | | Сколько минут занимает знакомство: длительность фильма или альбома, время чтения. |
| `details` | | Короткие факты списком: техника и музей, страна и жанр, лейбл. |
| `summary` | да | О чём это (до ~700 знаков). |
| `why` | | Почему стоит — личная рекомендация. |
| `lookFor` | | На что обратить внимание. Для картин это подсказки «медленного просмотра» (нужно хотя бы две). |
| `fact` | | Любопытный факт — отдельная карточка. |
| `more` | | Что посмотреть, послушать или прочитать дальше. |
| `keyTrack` | | Для альбомов: трек, с которого начать. По нему ищется 30-секундный фрагмент. |
| `url` | для статей | Адрес статьи (https). Статья открывается во встроенной читалке. |
| `source` | | Для статей — название издания в читалке. |
| `wiki` | | Статья Википедии в формате `ru:Охотники_на_снегу` или `en:The_Hunters_in_the_Snow`. Оттуда берётся изображение картины и ссылка «Подробнее». |
| `image` | | Прямая ссылка на изображение, если автоматический поиск не подходит. |
| `search` | | Для фильмов — международное название для поиска постера и трейлера в iTunes («The Wind Rises»). |

Пример картины:

```json
{
  "id": "painting-hunters-in-the-snow",
  "kind": "painting",
  "title": "Охотники на снегу",
  "originalTitle": "Jagers in de sneeuw",
  "creator": "Питер Брейгель Старший",
  "originalCreator": "Pieter Bruegel the Elder",
  "year": "1565",
  "minutes": 5,
  "details": ["Масло, дерево, 117 × 162 см", "Музей истории искусств, Вена"],
  "summary": "Охотники с собаками возвращаются в деревню…",
  "lookFor": ["Следы охотников на снегу.", "Конькобежцы на замёрзших прудах."],
  "wiki": "en:The_Hunters_in_the_Snow"
}
```

## Откуда берутся изображения

Ключи API не нужны:

- **Картины** — из статьи Википедии в поле `wiki`. Приложение берёт только свободные изображения
  (Wikimedia Commons), поэтому старые мастера находятся почти всегда. Для современных картин,
  защищённых авторским правом, свободного изображения обычно нет — тогда показывается аккуратная заглушка.
- **Альбомы и фильмы** — обложки, постеры, 30-секундные фрагменты и трейлеры из iTunes Search API
  (поиск по `originalCreator`/`creator` и `originalTitle`/`title`, для фильмов — сначала по `search`).
- Найденные ссылки кэшируются: приложение заранее скачивает изображения на сегодня и завтра,
  поэтому виджет показывает их и без сети.

## Проверка

```bash
python3 scripts/validate_catalog.py
```

Скрипт найдёт опечатки в названиях полей, повторяющиеся `id`, статьи без `url`, неверный формат `wiki`
и предупредит о необязательных, но полезных полях. Он же автоматически запускается в GitHub Actions при каждом коммите.

## Удалённый каталог

Чтобы добавлять выпуски без обновления приложения:

1. Выложите `catalog.json` по постоянному https-адресу — например, через GitHub Pages
   или как файл в публичном репозитории (`https://raw.githubusercontent.com/<логин>/<репозиторий>/<ветка>/catalog.json`).
2. Укажите адрес в `Shared/Core/AppConfig.swift`:
   ```swift
   static let remoteCatalogURL: URL? = URL(string: "https://…/catalog.json")
   ```
3. Пересоберите приложение. Дальше оно само проверяет файл раз в 6 часов и использует его,
   если дата в поле `updated` не старше, чем у встроенного каталога. Не забывайте обновлять `updated`.
